# Локализация

Интерфейс трекера доступен на **русском** и **английском** языках. Переключение языка меняет подписи в интерфейсе, но не ProductID, цены, ключи сопоставления, историю или решения автосинхронизации. Выбор языка сохраняется в браузере и входит в полную резервную копию JSON.

Если установленные файлы игры совпадают со встроенным каталогом, помощник получает официальные русские названия товаров через маршруты `/locales` и `/localization/ru-RU`. Названия сопоставляются по ProductID и ключам таблицы локализации игры. Названия брендов остаются такими, как в игре. Если игра не найдена, состав файлов изменился или перевод недоступен, показываются английские названия.

HTML-версия трекера работает вручную без помощника. Для официальных названий товаров из игры откройте страницу по локальному адресу помощника. Помощник только читает установленные файлы локализации.

Разработчики могут заново создать `data/game-localization.json` с помощью `tools/extract-game-localization.py` после проверки текущей версии игры, а затем пересобрать EXE. Файл `data/product-metadata.json` содержит идентификаторы ProductSO, необходимые для извлечения данных. Перед публикацией обновлённых метаданных запустите тесты локализации и проверьте, сколько товаров получили перевод.
