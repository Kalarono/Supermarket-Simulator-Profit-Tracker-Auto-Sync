# Решение проблем

| Симптом | Что проверить |
| --- | --- |
| Помощник недоступен | Запустите `SupermarketTrackerSync.exe`, закройте его старую копию и откройте `http://127.0.0.1:47831/`. |
| Сохранение не найдено | Сохраните игру хотя бы один раз, проверьте выбранный слот или запустите помощник с параметром `--save "<полный путь к файлу slot_0.es3>"`. |
| Предупреждение при чтении сохранения | Подождите, пока игра закончит запись. Помощник сохраняет последний корректный снимок и блокирует применение изменений, пока текущее чтение некорректно. |
| Неожиданные изменения цен | Нажмите **«Проверить изменения»** и откройте **«Проблемы сопоставления»**. Перед применением скачайте резервную копию. Неоднозначные соответствия автоматически не назначаются. |
| После перехода на локальный адрес пропали данные | У страниц с разными адресами отдельные браузерные хранилища. Скачайте полную резервную копию JSON в старом трекере и выберите **«Резервное копирование → Восстановление»** в трекере по локальному адресу. |
| Нет русских названий товаров | Проверьте выбор русского языка. После обновления игры помощник сохраняет встроенные названия и показывает предупреждение, если каталог устарел. Для разработческого обновления каталога см. [локализацию](localization.md). |
| Без интернета не отображаются диаграммы или шрифты | Исходный трекер загружает эти ресурсы через CDN. Проверьте подключение к интернету. |

Журнал помощника находится в `%LOCALAPPDATA%\SupermarketTrackerSync\logs\helper.log`; рядом сохраняются архивные журналы. В журнале могут быть локальные пути к сохранениям. Перед добавлением журнала к публичному сообщению об ошибке проверьте его и удалите личные данные.
