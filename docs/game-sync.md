# Синхронизация с игрой

Помощник для Windows читает выбранное сохранение Supermarket Simulator в формате `.es3` и открывает трекер по адресу `http://127.0.0.1:47831/`. Он ждёт завершения записи файла и при временной ошибке чтения сохраняет последний корректный снимок. Помощник не изменяет сохранение, файлы игры или запущенный процесс. HTTP-сервер принимает подключения только на `127.0.0.1` и предоставляет маршруты для чтения данных.

## Первый запуск

1. Запустите `SupermarketTrackerSync.exe` и проверьте выбранное сохранение в блоке **«Синхронизация с игрой»**.
2. Нажмите **«Проверить изменения»**, чтобы просмотреть подтверждённые соответствия ProductID и каждое предлагаемое изменение цены. Товары без соответствия и неоднозначные совпадения появятся в разделе **«Проблемы сопоставления»**.
3. Перед применением изменений или включением автосинхронизации скачайте полную резервную копию JSON.
4. Включайте **«Автосинхронизация»** после подтверждения. При большом числе изменений, смене слота сохранения, изменении сопоставления, некорректном снимке или устаревшей схеме цен автоматическое применение приостанавливается до проверки.
5. Кнопка **«Отменить последнюю синхронизацию»** откатывает последний пакет автосинхронизации, если это не затронет более поздние ручные правки. Отменённый снимок повторно не применяется, пока не появится новое сохранение.

Один и тот же снимок — с тем же именем файла, временем записи и хешем SHA-256 — применяется не более одного раза. Отсутствующие в сохранении значения не стирают данные трекера.

## Поля цен

| Поле трекера | Источник или расчёт |
| --- | --- |
| Закупочная цена у поставщика за единицу | Текущая цена товара в `PricingDatas` |
| Стоимость коробки при онлайн-заказе | Закупочная цена за единицу × количество единиц в коробке из ProductSO |
| Средняя себестоимость | Текущая стоимость запасов из `AverageCosts`, если она указана |
| Рыночная цена | Цена поставщика и оптимальная норма прибыли из ProductSO с округлением по правилам игры |
| Цена продажи игрока | `PricesSetByPlayer`, если значение указано |
| Цена закупки при самовывозе | Значение, введённое в трекере вручную; синхронизация его сохраняет |

Цвет точки статуса товара определяется по `LicenseProductsDatas` и сопоставлению лицензий игры: зелёный — товар активен, красный — отключён, серый — достоверный статус неизвестен. Минимальный порог прибыли влияет только на отображение товаров в трекере. Он не меняет сохранение и правила синхронизации.

## Данные и совместимость

В EXE встроены HTML-страница трекера, скрипты, таблица сопоставления, данные о ценах и каталог локализации. Применённые изменения по-прежнему хранятся в браузере. При переходе с `file://` на локальный адрес помощника перенесите данные через **«Резервное копирование → Скачать резервную копию»** и **«Резервное копирование → Восстановление»**: у этих страниц разные браузерные хранилища.

Текущие данные подготовлены для версии сохранения `v1.6.0(223)`. После изменения формата игры или появления нового ProductID проверьте сопоставление до обновления метаданных. Помощник предоставляет на локальном адресе маршруты `/status`, `/snapshot`, `/mapping-audit` и маршруты чтения локализации. Команда `--version` выводит версии помощника, схемы API и таблицы сопоставления; `--inspect-localization` проверяет установленные файлы локализации.
